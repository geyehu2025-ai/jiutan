# 酒探微信小程序

1. 微信开发者工具选择“导入项目”，目录指向本文件夹。
2. 预览可暂用 `touristappid`；正式发布前在 `project.config.json` 换成你的小程序 AppID。
3. 在微信公众平台 → 开发管理 → 开发设置 → 服务器域名，把 `https://geyehu2025-ai.github.io` 加入 `request` 合法域名。
4. 小程序读取与网页相同的 `https://geyehu2025-ai.github.io/jiutan/data.json`，不内置演示商品。

微信内不能任意打开淘宝、京东等外部网页，所以详情页提供“复制平台链接”和“复制操作步骤”，然后到对应 App 打开。
